# spur-instagram

The inbox read through the browser spur without opening a chat, so nothing shows Seen.

A [Switch](https://switch.ax) spur: a Python MCP server (`sbmcp.py`, a Switchboard appendage) that Switch runs through
[spur-kit](https://github.com/zachsents/spur-kit)'s shim. Its messages carry who sent them, for Switch's inbox and Contacts.

## Install

Ask Switch's agent to install `github:zachsents/spur-instagram`, or add it in the desktop's Spurs view (⌘K, Spurs). Switch runs it
on the first machine with what it needs (`always-on`).

## Setup

Needs the browser spur (`github:zachsents/spur-browser#a4e1fda` or later) on a machine whose Chrome is signed in to Instagram.
